# PRIMAL RESONANCE

Sito ufficiale basato sul progetto originale V22, con video Hyenak, menu, guerrieri, raccoglitore di 17 carte, romanzi e sezione videogioco.

## Pubblicazione

GitHub Pages: branch `main`, cartella `/ (root)`. `index.html` è nella directory principale. I contenuti originali sono in `assets/`.

Gli aggiornamenti a `main` vengono pubblicati allo stesso indirizzo GitHub Pages. Conservare il nome del repository e i percorsi relativi degli asset.

Il videogioco è in sviluppo: la V22 presenta la sezione informativa originale, senza demo giocabile.
